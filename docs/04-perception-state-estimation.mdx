## Overview

Perception and state estimation enable humanoid robots to understand their environment and their own state within it. This chapter covers computer vision, SLAM, and sensor fusion techniques.

## Computer Vision for Robotics

### Object Detection

**YOLO (You Only Look Once)**
- Real-time object detection
- Single-pass architecture
- 30-60 FPS on edge devices

**Faster R-CNN**
- Higher accuracy, slower speed
- Region proposal network
- Used for precise manipulation

### Semantic Segmentation

**DeepLab**
- Pixel-level classification
- Atrous convolution for multi-scale features

**Mask R-CNN**
- Instance segmentation
- Object detection + pixel masks

### Pose Estimation

**Human Pose Estimation**
- OpenPose, MediaPipe
- Keypoint detection
- Used for imitation learning

**Object 6D Pose**
- Position (x, y, z) + Orientation (roll, pitch, yaw)

## SLAM (Simultaneous Localization and Mapping)

### Visual SLAM

**ORB-SLAM3**
- Feature-based SLAM
- Works with monocular, stereo, RGB-D cameras
- Loop closure detection

**LSD-SLAM**
- Direct method (no feature extraction)
- Dense/semi-dense reconstruction

### LiDAR SLAM

**Cartographer**
- Google's 2D/3D SLAM
- Submap-based optimization

**LOAM (LiDAR Odometry and Mapping)**
- Real-time point cloud processing
- Low-drift odometry

### Visual-Inertial SLAM

**VINS-Mono**
- Fuses camera + IMU
- Robust to fast motion
- Monocular or stereo

## Sensor Fusion

### Kalman Filtering

**Extended Kalman Filter (EKF)**
```python
import numpy as np

class EKF:
    def __init__(self, state_dim, measurement_dim):
        self.x = np.zeros(state_dim)  # State
        self.P = np.eye(state_dim)     # Covariance
        self.Q = np.eye(state_dim) * 0.01  # Process noise
        self.R = np.eye(measurement_dim) * 0.1  # Measurement noise
    
    def predict(self, F, B=None, u=None):
        """Prediction step"""
        if B is not None and u is not None:
            self.x = F @ self.x + B @ u
        else:
            self.x = F @ self.x
        self.P = F @ self.P @ F.T + self.Q
    
    def update(self, z, H):
        """Update step"""
        y = z - H @ self.x  # Innovation
        S = H @ self.P @ H.T + self.R  # Innovation covariance
        K = self.P @ H.T @ np.linalg.inv(S)  # Kalman gain
        
        self.x = self.x + K @ y
        self.P = (np.eye(len(self.x)) - K @ H) @ self.P
```

**Unscented Kalman Filter (UKF)**
- Better for nonlinear systems
- Sigma point sampling

### Particle Filters

- Non-parametric Bayesian filtering
- Multiple hypotheses (particles)
- Used in localization (Monte Carlo Localization)

## State Estimation

### Robot State

**Position and Orientation**
- Global position (x, y, z)
- Orientation (quaternion or Euler angles)
- Estimated via SLAM or GPS

**Velocity**
- Linear velocity (vx, vy, vz)
- Angular velocity (ωx, ωy, ωz)
- From IMU integration or differentiation

**Joint States**
- Position, velocity, effort for each joint
- From encoders and current sensors

### Environment State

**Occupancy Grids**
- 2D/3D grid representation
- Each cell: free, occupied, unknown
- Updated via sensor measurements

**Point Clouds**
- 3D points from LiDAR or depth cameras
- Downsampling with voxel grids
- Registration with ICP (Iterative Closest Point)

## Depth Estimation

### Stereo Vision

**Disparity Calculation**
```python
import cv2
import numpy as np

def compute_depth(left_img, right_img, baseline, focal_length):
    """Compute depth from stereo images"""
    # Create stereo matcher
    stereo = cv2.StereoBM_create(numDisparities=16*5, blockSize=15)
    
    # Compute disparity
    disparity = stereo.compute(left_img, right_img)
    
    # Convert to depth
    # depth = (baseline * focal_length) / disparity
    depth = np.zeros_like(disparity, dtype=np.float32)
    mask = disparity > 0
    depth[mask] = (baseline * focal_length) / disparity[mask]
    
    return depth
```
