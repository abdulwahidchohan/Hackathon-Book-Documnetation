### Collision Detection and Avoidance

```python
class CollisionMonitor(Node):
    def __init__(self):
        super().__init__('collision_monitor')
        
        # Subscribe to joint torques
        self.torque_sub = self.create_subscription(
            JointState, '/joint_states', self.torque_callback, 10
        )
        
        # Emergency stop publisher
        self.estop_pub = self.create_publisher(Bool, '/emergency_stop', 10)
        
        self.torque_threshold = 50.0  # Nm
    
    def torque_callback(self, msg):
        # Check for unexpected torques (collision)
        for effort in msg.effort:
            if abs(effort) > self.torque_threshold:
                self.get_logger().warn('Collision detected!')
                self.trigger_estop()
    
    def trigger_estop(self):
        msg = Bool()
        msg.data = True
        self.estop_pub.publish(msg)
```

### Safe Motion Planning

**Velocity and Acceleration Limits**
```python
def check_trajectory_safety(trajectory):
    """Verify trajectory meets safety constraints"""
    max_velocity = 1.0  # m/s
    max_acceleration = 2.0  # m/s^2
    
    for i in range(len(trajectory) - 1):
        dt = trajectory[i+1].time - trajectory[i].time
        
        # Check velocity
        velocity = (trajectory[i+1].position - trajectory[i].position) / dt
        if abs(velocity) > max_velocity:
            return False
        
        # Check acceleration
        if i > 0:
            prev_velocity = (trajectory[i].position - trajectory[i-1].position) / dt
            acceleration = (velocity - prev_velocity) / dt
            if abs(acceleration) > max_acceleration:
                return False
    
    return True
```

## Human-Robot Interaction Safety

### Personal Space
- Maintain minimum distance (0.5-1.0m)
- Slow down when humans approach
- Stop if distance < safety threshold

### Intent Recognition

```python
def predict_human_intent(human_pose, human_velocity):
    """Predict if human is approaching robot"""
    # Calculate trajectory
    predicted_position = human_pose + human_velocity * 2.0  # 2 seconds
```

## Ethical Frameworks

### Asimov's Laws (Updated)

1. **Do No Harm**: Robots must not harm humans or allow harm through inaction
2. **Obey Orders**: Follow human commands unless they conflict with the first law
3. **Self-Preservation**: Protect own existence unless it conflicts with laws 1 or 2

## Privacy and Data Protection

### Data Minimization

```python
class PrivacyPreservingVision(Node):
    def __init__(self):
        super().__init__('privacy_vision')
        
        self.image_sub = self.create_subscription(
            Image, '/camera/image', self.image_callback, 10
        )
    
    def image_callback(self, msg):
        # Blur faces for privacy
        image = self.bridge.imgmsg_to_cv2(msg)
        faces = self.detect_faces(image)
        
        for (x, y, w, h) in faces:
            # Blur face region
            face_region = image[y:y+h, x:x+w]
            blurred = cv2.GaussianBlur(face_region, (99, 99), 30)
            image[y:y+h, x:x+w] = blurred
        
        # Process anonymized image
        self.process_image(image)
```

```python
def explain_decision(observation, action, model):
    """Explain why robot took specific action"""
    # SHAP values for feature importance
    explainer = shap.Explainer(model)
    shap_values = explainer(observation)
    
    # Get top contributing features
    top_features = np.argsort(np.abs(shap_values))[-5:]
    
    explanation = f"Action '{action}' was chosen because:\n"
    for feature_idx in top_features:
        explanation += f"- {feature_names[feature_idx]}: {shap_values[feature_idx]:.3f}\n"
    
    return explanation
```

## Summary

Safety and ethics in humanoid robotics require:
- **Technical Safety**: Collision detection, safe planning, redundancy
- **HRI Safety**: Personal space, intent recognition, compliant control
- **Ethics**: Do no harm, transparency, accountability
- **Privacy**: Data minimization, anonymization
- **Fairness**: Bias detection and mitigation
- **Deployment**: Risk assessment, testing, certification

Responsible development ensures humanoid robots benefit society while minimizing risks.
