## Overview

Simulation is essential for developing and testing humanoid robots safely and efficiently. This chapter covers Gazebo, NVIDIA Isaac Sim, Unity, and other simulation tools.

## Gazebo Classic vs. Gazebo (Ignition)

### Gazebo Classic
- Legacy ROS 1 simulator
- Wide plugin ecosystem
- Being phased out

### Gazebo (Ignition/Gazebo Sim)
- Modern architecture
- Better performance
- Native ROS 2 integration
- Photorealistic rendering

## Setting Up Gazebo Simulation

### Robot Description (URDF/SDF)

```xml
<?xml version="1.0"?>
<sdf version="1.8">
  <model name="humanoid_robot">
    <link name="base_link">
      <inertial>
        <mass>50.0</mass>
        <inertia>
          <ixx>1.0</ixx>
          <iyy>1.0</iyy>
          <izz>1.0</izz>
        </inertia>
      </inertial>
      
      <visual name="visual">
        <geometry>
          <mesh><uri>model://humanoid/meshes/torso.dae</uri></mesh>
        </geometry>
      </visual>
      
      <collision name="collision">
        <geometry>
          <box><size>0.3 0.2 0.5</size></box>
        </geometry>
      </collision>
    </link>
    
    <!-- Sensors -->
    <sensor name="camera" type="camera">
      <camera>
        <horizontal_fov>1.047</horizontal_fov>
        <image>
          <width>640</width>
          <height>480</height>
        </image>
      </camera>
      <update_rate>30</update_rate>
    </sensor>
  </model>
</sdf>
```

### Launch File

```python
from launch import LaunchDescription
from launch_ros.actions import Node
from launch.actions import IncludeLaunchDescription

def generate_launch_description():
    return LaunchDescription([
        # Start Gazebo
        IncludeLaunchDescription(
            'path/to/gazebo.launch.py',
            launch_arguments={'world': 'humanoid_world.sdf'}.items()
        ),
        
        # Spawn robot
        Node(
            package='ros_gz_sim',
            executable='create',
            arguments=['-name', 'humanoid', '-file', 'humanoid.sdf'],
        ),
        
        # Robot state publisher
        Node(
            package='robot_state_publisher',
            executable='robot_state_publisher',
            parameters=[{'robot_description': robot_description}]
        ),
    ])
```

## NVIDIA Isaac Sim

### Advantages
- RTX ray tracing for photorealism
- PhysX 5 for accurate physics
- Synthetic data generation
- Domain randomization

### Basic Setup

```python
from omni.isaac.kit import SimulationApp

# Start simulation
simulation_app = SimulationApp({"headless": False})

from omni.isaac.core import World
from omni.isaac.core.robots import Robot

# Create world
world = World()

# Add robot
robot = world.scene.add(Robot(prim_path="/World/Humanoid", name="humanoid"))

# Run simulation
world.reset()
for i in range(1000):
    world.step(render=True)

simulation_app.close()
```

## Unity for Robotics

### Unity Robotics Hub
- ROS-Unity integration
- Perception tools
- Simulation environments

### Example: ROS Communication

```csharp
using Unity.Robotics.ROSTCPConnector;
using RosMessageTypes.Geometry;

public class RobotController : MonoBehaviour
{
    ROSConnection ros;
    
    void Start()
    {
        ros = ROSConnection.GetOrCreateInstance();
        ros.Subscribe<TwistMsg>("/cmd_vel", CmdVelCallback);
    }
    
    void CmdVelCallback(TwistMsg msg)
    {
        // Move robot based on Twist message
        transform.Translate(
            msg.linear.x * Time.deltaTime,
            0,
            msg.linear.z * Time.deltaTime
        );
    }
}
```

## Sim-to-Real Transfer

### Domain Randomization

```python
import random

def randomize_environment():
    """Randomize simulation parameters"""
    # Lighting
    light_intensity = random.uniform(0.5, 2.0)
    
    # Object properties
    friction = random.uniform(0.3, 0.9)
    mass = random.uniform(0.8, 1.2)
    
    # Camera noise
    noise_std = random.uniform(0.0, 0.05)
    
    return {
        'light': light_intensity,
        'friction': friction,
        'mass': mass,
        'noise': noise_std
    }
```
